# 📸 Портфолио Арины Куряшкиной — Инструкция по развертыванию и управлению

## 🚀 Быстрый старт на Vercel (Бесплатно)

Vercel — это **бесплатный хостинг** для статических сайтов и React приложений. Это лучший выбор для вашего портфолио.

### Шаг 1: Подготовка на GitHub

1. Создайте аккаунт на [GitHub.com](https://github.com) (если его нет)
2. Создайте новый репозиторий с названием `arina-portfolio`
3. Загрузьте файлы проекта в репозиторий:
   ```bash
   git clone https://github.com/ВАШ_GITHUB_ЛОГИН/arina-portfolio.git
   cd arina-portfolio
   # Скопируйте все файлы из архива сюда
   git add .
   git commit -m "Initial commit"
   git push origin main
   ```

### Шаг 2: Развертывание на Vercel

1. Перейдите на [vercel.com](https://vercel.com)
2. Нажмите "Sign Up" и выберите "Continue with GitHub"
3. Авторизуйтесь через GitHub
4. Нажмите "New Project"
5. Выберите репозиторий `arina-portfolio`
6. Нажмите "Deploy"

**Готово!** Ваш сайт будет доступен по адресу вроде: `https://arina-portfolio.vercel.app`

## 📷 Как добавлять новые фотографии

### Способ 1: Через GitHub (Рекомендуется)

Это самый простой способ для добавления фотографий.

#### Шаг 1: Подготовьте фотографию
- Размер: оптимально 1200x1600 пикселей (вертикальное фото)
- Формат: JPG или PNG
- Размер файла: не более 2 МБ

#### Шаг 2: Добавьте фото в папку
1. Откройте репозиторий на GitHub
2. Перейдите в папку `client/public/portfolio/`
3. Нажмите "Add file" → "Upload files"
4. Загрузите вашу фотографию (например, `image5.jpg`)

#### Шаг 3: Добавьте фото в список портфолио
1. Откройте файл `client/src/pages/Home.tsx`
2. Найдите раздел `const portfolioItems = [`
3. Добавьте новый элемент перед закрывающей скобкой:

```typescript
{
  id: 5,
  title: "Название вашей работы",
  category: "Портреты",  // или "Мода", "Арт", "События"
  image: "/portfolio/image5.jpg",
},
```

Пример полного списка:
```typescript
const portfolioItems = [
  {
    id: 1,
    title: "Портретный сеанс",
    category: "Портреты",
    image: "/portfolio/image1.jpg",
  },
  {
    id: 2,
    title: "Редакционная мода",
    category: "Мода",
    image: "/portfolio/image2.jpg",
  },
  // ... остальные фото ...
  {
    id: 5,
    title: "Новая работа",
    category: "Портреты",
    image: "/portfolio/image5.jpg",  // ← НОВОЕ ФОТО
  },
];
```

#### Шаг 4: Сохраните изменения
1. Нажмите "Commit changes"
2. Напишите сообщение: "Add new portfolio image"
3. Нажмите "Commit"

**Vercel автоматически обновит сайт в течение 1-2 минут!**

### Способ 2: Локальное редактирование (Для опытных)

Если вы хотите работать на своем компьютере:

1. **Установите необходимое:**
   - [Node.js](https://nodejs.org/) (версия 18+)
   - [Git](https://git-scm.com/)

2. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/arina-portfolio.git
   cd arina-portfolio
   ```

3. **Установите зависимости:**
   ```bash
   npm install
   # или
   pnpm install
   ```

4. **Добавьте фото:**
   - Скопируйте фотографию в папку `client/public/portfolio/`
   - Отредактируйте файл `client/src/pages/Home.tsx` (добавьте элемент в `portfolioItems`)

5. **Протестируйте локально:**
   ```bash
   npm run dev
   ```
   Откройте браузер: `http://localhost:5173`

6. **Загрузьте на GitHub:**
   ```bash
   git add .
   git commit -m "Add new portfolio images"
   git push origin main
   ```

7. **Vercel автоматически обновит сайт!**

## 📝 Редактирование других элементов

### Изменение контактной информации

Откройте `client/src/pages/Home.tsx` и найдите раздел контактов:

```typescript
<a href="mailto:arina@photography.com">
  arina@photography.com
</a>

<a href="tel:+7(999)123-45-67">
  +7 (999) 123-45-67
</a>

<a href="https://instagram.com/arina.kuryashkina">
  @arina.kuryashkina
</a>
```

Замените на свои данные.

### Изменение цен

Найдите раздел `const services = [` и отредактируйте поля `price` и `duration`:

```typescript
{
  id: "portraits",
  title: "Портретные сеансы",
  description: "...",
  price: "₽8000 - ₽15000",  ← Измените цену
  duration: "1-2 часа",      ← Измените длительность
},
```

### Изменение описания услуг

Отредактируйте поле `description` в том же разделе:

```typescript
description: "Новое описание вашей услуги",
```

### Изменение цветовой схемы

Откройте `client/src/index.css` и отредактируйте переменные в разделе `:root`:

```css
:root {
  --primary: oklch(0.35 0.15 30);  ← Основной цвет (коричневый)
  --background: oklch(0.98 0.001 0);  ← Цвет фона
  /* ... остальные цвета ... */
}
```

## ⚠️ Важные замечания

1. **Размер фотографий:** Используйте оптимизированные изображения (не более 2 МБ каждое)
2. **Формат:** JPG лучше для фотографий, PNG для изображений с прозрачностью
3. **Имена файлов:** Используйте латинские буквы и цифры (например: `portrait_01.jpg`)
4. **Резервная копия:** Регулярно делайте резервные копии репозитория
5. **Обновления:** После каждого изменения Vercel автоматически пересоберет сайт (1-2 минуты)

## 🆘 Решение проблем

### Сайт не обновляется после загрузки фото
- Подождите 2-3 минуты (Vercel пересобирает сайт)
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Проверьте статус деплоя на [vercel.com](https://vercel.com)

### Фото не отображается
- Проверьте, что файл загружен в папку `client/public/portfolio/`
- Проверьте имя файла в коде (должно совпадать с именем на диске)
- Убедитесь, что расширение файла правильное (.jpg, .jpeg, .png)

### Ошибка при деплое
- Проверьте синтаксис в файле `Home.tsx` (могут быть опечатки)
- Убедитесь, что все кавычки закрыты
- Проверьте логи деплоя на Vercel
