## 1. Создание репозитория на GitHub

### Шаг 1.1: Регистрация на GitHub

1. Откройте [github.com](https://github.com)
2. Нажмите **"Sign up"** (если нет аккаунта)
3. Введите:
   - Email: ваша почта
   - Password: надежный пароль
   - Username: `arina-portfolio` (или любое другое имя)
4. Нажмите **"Create account"**
5. Подтвердите email (проверьте почту)

### Шаг 1.2: Создание нового репозитория

1. После входа нажмите на иконку профиля (верхний правый угол)
2. Выберите **"Your repositories"**
3. Нажмите зелёную кнопку **"New"**
4. Заполните форму:
   - **Repository name:** `arina-portfolio`
   - **Description:** `Professional photographer portfolio`
   - **Public:** ✅ (обязательно выберите Public)
   - **Add a README file:** ✅ (отметьте)
5. Нажмите **"Create repository"**

✅ **Готово!** Вы создали пустой репозиторий

## 2. Загрузка файлов в репозиторий

### Способ A: Через веб-интерфейс GitHub (Самый простой)

#### Шаг 2A.1: Распакуйте архив

1. Скачайте файл `arina_portfolio_source.tar.gz`
2. Распакуйте его:
   - **На Windows:** используйте 7-Zip или WinRAR
   - **На Mac:** двойной клик на файл
   - **На Linux:** `tar -xzf arina_portfolio_source.tar.gz`

Вы получите папку `arina_kuryashkina_portfolio` со всеми файлами.

#### Шаг 2A.2: Загрузите файлы на GitHub

1. Откройте ваш репозиторий: `github.com/ВАШ_ЛОГИН/arina-portfolio`
2. Нажмите **"Add file"** → **"Upload files"**
3. Перетащите все файлы из папки `arina_kuryashkina_portfolio` в окно браузера
   - Скопируйте содержимое папки (не саму папку!)
   - Должны быть видны файлы: `package.json`, `client/`, `server/`, и т.д.
4. Внизу нажмите **"Commit changes"**
5. Напишите сообщение: `Initial commit - portfolio setup`
6. Нажмите **"Commit changes"**

✅ **Готово!** Файлы загружены на GitHub

## 3. Подключение к Vercel

### Шаг 3.1: Регистрация на Vercel

1. Откройте [vercel.com](https://vercel.com)
2. Нажмите **"Sign Up"**
3. Выберите **"Continue with GitHub"**
4. Авторизуйтесь через GitHub
5. Vercel попросит доступ к вашим репозиториям — нажмите **"Authorize"**

### Шаг 3.2: Создание проекта на Vercel

1. После входа вы попадёте на главную страницу Vercel
2. Нажмите кнопку **"New Project"** (или **"Add New..."** → **"Project"**)
3. В списке репозиториев найдите **`arina-portfolio`**
4. Нажмите на него

### Шаг 3.3: Настройка проекта

1. На странице импорта проекта вы увидите:
   - **Project Name:** `arina-portfolio` (оставьте как есть)
   - **Framework Preset:** выберите **"Other"** (или оставьте пустым)
   - **Root Directory:** оставьте пустым

2. Нажмите **"Deploy"**

⏳ **Подождите 2-3 минуты** — Vercel будет собирать проект

✅ **Готово!** Вы увидите сообщение "Congratulations! Your site is live"

### Шаг 3.4: Получение ссылки на сайт

1. После успешного деплоя вы увидите ссылку вроде:
   ```
   https://arina-portfolio.vercel.app
   ```
2. Нажмите на неё — откроется ваш сайт!

✅ **Ваш сайт уже в интернете!**

## 4. Настройка бесплатного домена

### Вариант 1: Бесплатный поддомен на Vercel (Рекомендуется)

Vercel автоматически предоставляет бесплатный поддомен `.vercel.app`

```

```

Это полностью бесплатно и достаточно для портфолио!

---

### Вариант 2: Собственный домен (Если хотите свой домен)

#### Способ 2.1: Купить домен на Namecheap (дешево)

1. Откройте [namecheap.com](https://www.namecheap.com)
2. В поле поиска введите: `arinaphotography.ru` (или другое имя)
3. Нажмите **"Search"**
4. Выберите домен из списка
5. Нажмите **"Add to Cart"**
6. Нажмите **"View Cart"** → **"Checkout"**
7. Создайте аккаунт или войдите
8. Заполните информацию и оплатите

**Стоимость:** от $5-10 в год

#### Способ 2.2: Подключить домен к Vercel

1. В Vercel откройте ваш проект
2. Перейдите в **"Settings"** → **"Domains"**
3. Нажмите **"Add Domain"**
4. Введите ваш домен: `arinaphotography.ru`
5. Нажмите **"Add"**
6. Vercel покажет инструкции по настройке DNS

#### Способ 2.3: Настроить DNS на Namecheap

1. На Namecheap откройте **"Manage"** для вашего домена
2. Перейдите в **"Advanced DNS"**
3. Удалите старые записи (кроме CNAME и MX)
4. Добавьте новую запись:
   - **Type:** CNAME
   - **Host:** @
   - **Value:** `cname.vercel-dns.com`
5. Нажмите **"Save All Changes"**

⏳ **Подождите 24-48 часов** — DNS обновится

✅ **Готово!** Ваш сайт будет доступен по адресу `arinaphotography.ru`

## 🆘 Решение проблем

### Проблема: "Repository not found" при подключении Vercel

**Решение:**
1. Убедитесь, что репозиторий **Public** (не Private)
2. Проверьте, что вы вошли в GitHub на Vercel
3. Переавторизуйтесь: нажмите на профиль → "Settings" → "Connected Accounts" → переподключите GitHub

### Проблема: Сайт показывает ошибку после деплоя

**Решение:**
1. Откройте Vercel → ваш проект → "Deployments"
2. Посмотрите логи (нажмите на последний деплой)
3. Ищите красные ошибки в логах
4. Обычно это ошибки в синтаксисе кода — проверьте файл `Home.tsx`

### Проблема: Домен не работает через 24 часа

**Решение:**
1. Проверьте DNS записи на Namecheap (Advanced DNS)
2. Используйте инструмент проверки: [dnschecker.org](https://dnschecker.org)
3. Попробуйте очистить кэш браузера (Ctrl+Shift+Delete)
4. Подождите ещё 24 часа (DNS может обновляться долго)

### Проблема: Vercel требует платный план

**Решение:**
- Это не должно происходить для статических сайтов
- Убедитесь, что вы используете бесплатный план
- Проверьте в Settings → Billing
